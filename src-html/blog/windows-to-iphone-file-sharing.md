**qrr.app** is a browser-based tool that enables instant file sharing between devices, without installing anything and without creating accounts.

## The problem with sharing files from Windows to iPhone

Standard methods of sharing files between Windows and iPhone are cumbersome. AirDrop only works in the Apple ecosystem, and Bluetooth/Nearby Share doesn't support iOS. Email, cloud, or cable can be tedious and time-consuming.

## How qrr.app solves this problem?

Simply open `https://qrr.app` in a browser on Windows, create a session, and share the generated code or link with the receiver on iPhone. iPhone connects via browser and you can immediately start sharing files without accounts, login, or installation.

> "You don't need to install any app, log in, or remember complicated settings. The connection is direct and lasts as long as you have browser tabs open."

## Why use qrr.app?

- ✅ Works in every modern browser  
- ✅ No installation or registration required  
- ✅ Session lasts only as long as needed — no traces after ending  
- ✅ Seamless sharing between Windows, iOS, Android, macOS, Linux  

## Quick step-by-step guide

1. On Windows open `https://qrr.app` and click "New session".
2. On iPhone open the camera and scan the generated QR code or enter the code manually.
3. Connected devices can immediately share files, texts, and long links.
4. When done, just close the tab — the session expires, files disappear.

## Summary

**qrr.app** is a fast and convenient alternative to traditional methods of sharing files between Windows and iPhone. Works instantly, without unnecessary complications and installation. Perfect when you need to share a file "right now".
