**qrr.app** as a PWA on Android is more than just a saved homepage shortcut. With **Share Target API** support, you can share files and texts directly from any app, without opening a browser or copying links.

## What is PWA and Share Target API?

#### PWA (Progressive Web App) 
is a web app that can be installed on the home screen, works like a native app, but without a store installer.
#### Share Target API
allows the PWA to open in response to a "Share" action from Android – meaning when you choose "Share" for text or a file in any app, you'll see qrr.app as a target.

## Why install qrr.app as a PWA?

1. 📲 **Instant sharing**  
   – instead of opening a browser and navigating to the site, select "qrr.app" from the share menu  
2. ⚡ **Multi-file support**  
   – you can send multiple photos, documents, or text snippets at once  
3. 🔄 **No account creation or login**  
   – everything works on a one-time session basis  
4. 🆓 **Works offline until session is passed**  
   – Share Target API passes data even when you have temporarily weak internet  
5. 🤝 **Compatibility**  
   – works on any modern Android with Chromium-based browser (Chrome, Edge, Opera)

> **Note**: Share Target API is only available on Android – and in Chromium-based browsers (Chrome, Edge, Opera).

**Additional benefit:** 

After installing qrr.app as a PWA, scanning a QR code with the built-in phone camera will immediately open the installed app instead of a new browser tab.  
  
 This avoids a mess of open tabs. The solution ensures a smoother transition from scanning the code to sharing files – no delays and no need to reload the page. It's the perfect enhancement for anyone who values speed and interface minimalism.  

## How to install and use?

1. Open in Chrome on Android: <code>https://qrr.app</code>  
2. In the browser menu select **"Install app"** (or "Add to home screen")  
3. Allow PWA installation – the qrr.app icon will appear on the home screen  
4. When you want to share a file or text from any app, select **"Share" → qrr.app**  
5. In the opened PWA window, select or drop files, text will appear in the field and send
